生信和统计的日常，有一个反复出现的断裂。

想知道一个耐药突变落在哪，对话里给我的是一句「S315T 位于活性口袋边缘，与配体形成氢键」。读起来清楚，**脑子里那个画面却得自己拼**——拼不出来，就只能点头。

想跑一次方差分析：数据在本地 → 打开 SPSS → 点选检验 → 读表 → 数字抄进 Excel → 画图 → 截图 → 贴回对话让 AI 看。六个软件、七八次复制粘贴，而中间任何一步画出来的图，**都不是 AI 看到的那一张**。

分析这件事本身，从来不是文字能装下的：**结构是三维的，分布是有形状的。**

**SciViz 就是把这两半合回一屏。**

**三维结构查看器**
PDB / mmCIF，本地文件、4 位 PDB ID 或网址都能读。五种表现（卡通 / 骨架 / 球棍 / 空间填充 / 仅配体），六种着色（按链 / 二级结构 / B 因子 / 残基性质 / 彩虹 / 元素），突变位点标红、肽链 N 端标绿 C 端标紫，还能把镜头推进到指定残基附近、把远处淡掉。
它说「300 号残基在口袋底部」，那个残基就在同一块屏幕上标着红——省掉的是大量「在第 315 位附近、靠左上那个螺旋的右下角」式的描述。**这种句子写起来费劲，读起来更容易错。**

**统计图表（算和画一起完成）**
正态分布曲线、t 分布拒绝域、F 分布、箱线图 + 抖动散点、直方图 + 正态拟合、Q-Q 图、效应量森林图、残差图、功效曲线、KM 生存曲线（带删失竖杠 + log-rank）、ROC（正方形绘图区 + AUC + 最佳切点）。
**p 值是精确算的**（不完全 Beta / Gamma 函数），546 项与 scipy 逐项对拍零超差；log-rank 的 χ² 相对误差 1.2×10⁻¹⁶，AUC 精确吻合。如果图很漂亮但数字不可信，那它只是装饰。

**基因组学可视化**
进化树（Newick，支持分支长度 / bootstrap）、多序列比对（残基按性质着色 + 保守度轨道）、GO/KEGG 富集气泡图、全基因组变异分布（SNP/INDEL 与 CNV/SV 分层）、覆盖度轨道（带基因模型）、火山图、热图（可选行列层次聚类）、序列 Logo、基因互作网络。
真实数据规模也测过：**2.4 万个变异**会画成 496 根密度柱——逐点画会糊成一条实线，等于没画。

**真作业验证过**
卫生统计实习四例 9.1，三种饲料喂养贫血模型大鼠、每组 12 只：组间 SS = 52.1258，组内 SS = 20.0381，**F = 42.9221，p = 6.58×10⁻¹⁰**，η² = 0.7223，方差齐性检验 p = 0.615。课件里 SPSS 的结论是 P < 0.001、三组两两间均有差别——**对得上**。

**几个我比较在意的细节**
面板里的图是浏览器用 Canvas 画的，我给这套绘制代码配了个「录制器」，能把同一份绘制指令录成 SVG 再转 PNG——于是 **AI 能真的看到自己画出来的那张图，而不是假设它画对了**。听起来是工程细节，但它其实是「共享视野」能成立的前提：**要一起看，它得先看得见。** 所有面板都能导出 SVG 矢量图，投稿直接能用。
3.0.1 还加了「⧉ 独立窗口」：把可视化丢进一个真·独立窗口，拖到聊天框旁边或者全屏放到第二块屏。

**克制的地方**
零 npm 依赖、零构建步骤，整个目录约 1.2 MB，拷走就能用；没有引入任何图表库和分子可视化库，都是照需求手写的，所以也不存在「装不上依赖」这回事。195 个科研技能的完整正文随插件一起分发，装上就自动注册进 DSH，不用另配目录。

**想请你帮忙的地方**

我缺的不是夸奖，是**真实的失败案例**。如果你手头正好有数据，麻烦试这四件事：

1. 能不能装上（装不上请把系统版本 + 报错原文发我）
2. 拿你手头的 SPSS / R / GraphPad 结果对一下数字，看敢不敢信
3. 你专业里最想让它画、但它现在画不出来的那类图是什么
4. 图丑在哪（刻度、配色、标签重叠、比例）
