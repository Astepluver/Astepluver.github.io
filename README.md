# SciViz · 与 AI 的互动，不止于对话

生信分析时和 AI 协作，交互几乎全是文字：我说要什么，它回一段说明、一段代码、几张表。
可分析这件事本身，从来不是文字能装下的 —— **结构是三维的，分布是有形状的**。
于是一次分析总被迫切成两半：一半在对话里，一半在别的软件里。

这个插件的全部目的，就是**把「看的」和「说的」放进同一个界面**：
一次分析在 DeepSeek Harness 上一次性走完，不用在几个软件之间来回搬数据，
也不用对着「一个由 964 个残基组成的细长螺旋束」这样的句子自己拼画面 ——
**你和 AI 一起，共享一份视野。**

## 被切开的那些瞬间

- 想知道一个耐药突变落在哪：对话里是「S315T 位于活性口袋边缘，与配体形成氢键」。
  读起来清楚，脑子里那个画面却得自己拼 —— 拼不出来，就只能点头。
- 想跑一次方差分析：数据在本地 → 打开 SPSS → 点选检验 → 读表 → 数字抄进 Excel →
  画图 → 截图 → 贴回对话让 AI 看。六个软件、七八次复制粘贴，
  而中间任何一步画出来的图，**都不是 AI 看到的那一张**，它只能听我转述。

## 它做了什么

![三维结构查看器](https://Astepluver.github.io/images/sciviz-structure.png)

*六条链各一种颜色，每条链的 N 端标绿、C 端标紫 —— 这些端点原来只会出现在「肽链两端」四个字里。*

| 能力 | 说明 |
|---|---|
| **三维结构查看器** | PDB / mmCIF，本地文件、4 位 PDB ID 或网址都能读。五种表现（卡通 / 骨架 / 球棍 / 空间填充 / 仅配体），六种着色（按链 / 二级结构 / B 因子 / 残基性质 / 彩虹 / 元素），突变位点标红、肽链两端标绿紫，还能把镜头推进到指定残基附近、把远处淡掉 |
| **统计图表** | 正态分布曲线、t 分布拒绝域、F 分布、箱线图 + 抖动散点、直方图 + 正态拟合、Q-Q 图、效应量森林图、残差图、功效曲线。**算和画一起完成**，不是「跑完给你一串数字」 |
| **技能库** | 195 个科研技能的完整正文**随插件一起分发**，装上就注册进 DSH，不用另配目录 |

![方差分析](https://Astepluver.github.io/images/sciviz-anova.png)

*一次 ANOVA 出来的三个面板：F 分布与观测值、各组分布与 95% 置信区间、事后两两比较的效应量森林图。*

关键在于这些图**和对话在同一屏**：它说「300 号残基在口袋底部」，那个残基就在同一块屏幕上标着红。
省掉的是大量「在第 315 位附近、靠左上那个螺旋的右下角」式的描述 ——
**这种句子写起来费劲，读起来更容易错。**

## 拿真作业试过

不是演示动画。用卫生统计实习四的例 9.1 跑了一遍：三种饲料喂养贫血模型大鼠，
每组 12 只，比较红细胞数。

| 来源 | SS | df | MS | F | p |
|---|---|---|---|---|---|
| 组间 | 52.1258 | 2 | 26.0629 | **42.9221** | 6.58 × 10⁻¹⁰ |
| 组内 | 20.0381 | 33 | 0.6072 | | |
| 总计 | 72.1639 | 35 | | | |

η² = 0.7223，方差齐性检验 p = 0.615。课件里 SPSS 的结论是 P < 0.001、三组两两间均有差别，
**对得上**。p 值是自己算的精确值（不完全 Beta / Gamma 函数），
546 项与 scipy 逐项对拍，零超差 —— 如果图很漂亮但数字不可信，那它只是装饰。

## 一个我比较在意的细节

面板里的图是浏览器用 Canvas 画的。我给这套绘制代码配了一个「录制器」，
能把同一份绘制指令录成 SVG、再转成 PNG ——
于是 **AI 能真的看到自己画出来的那张图，而不是假设它画对了**。

听起来是工程细节，但它其实是「共享视野」能成立的前提：**要一起看，它得先看得见**。
装这个能力之前，我遇到过好几次「面板上一片空白」，而对面只能猜；
把画面变成双方都能检查的东西之后，问题一次就定位了。

## 克制的地方

零 npm 依赖、零构建步骤，整个目录约 1.2 MB，拷贝走就能用。
没有引入任何图表库和分子可视化库，都是照着需求手写的，因此也不存在「装不上依赖」这回事。

**不做的事也说清楚**：技能附属的脚本与参考文件合计约 59 MB，没有打进包，
只在各自正文里写明需要什么；方差分析里 F 值远大于临界值时，F 分布图的横轴会被拉长，
图是对的但不好看；服务只在本机回环上开，不对外。

## 下载与安装

**[dsh-sci-viz-2.0.0.tgz](https://Astepluver.github.io/files/plugins/dsh-sci-viz-2.0.0.tgz)**（约 1 MB，MIT）
· [sha256 校验和](https://Astepluver.github.io/files/plugins/dsh-sci-viz-2.0.0.sha256.txt)
· [源码 zip](https://Astepluver.github.io/files/plugins/dsh-sci-viz-2.0.0.zip)

> **用 `.tgz` 那个，不要用 zip。** DSH 的插件安装框只认四种规格：npm 包名、GitHub 仓库地址、
> 本地绝对目录路径、**.tgz / .tar.gz 直链** —— zip 不在其中。所以：

```
1. DSH → 设置 → 插件，在安装框里粘贴这一行：
   https://Astepluver.github.io/files/plugins/dsh-sci-viz-2.0.0.tgz
2. 等它装完（列表里会出现 dsh-sci-viz 2.0.0）
3. 重启一次 DSH
4. 刷新页面，右下角会出现一枚可拖动的药丸图标，点它打开面板
```

**没有网络 / 想手动装**：下载 zip 解压，在**同一个安装框**里填解压出来的目录的**绝对路径**
（例如 `C:\Users\你\Downloads\dsh-sci-viz`）。不要填 zip 文件本身的路径。

第 3 步不能省：插件分两半，负责计算的宿主半边是 ESM 模块，Node 按 URL 缓存，
改完只有重启才会重新加载。装好之后可以打开
`http://127.0.0.1:19387/api/sci-viz/health` 自查 ——
看到 `registry.ours: 195` 就说明 195 个技能全部注册成功了。

## 更新说明

### 2.0.0 · 基因组学可视化

1.0 解决的是一类问题：不要再用文字描述三维结构和统计结果。2.0 把同一件事推广到 DNA / RNA ——
技能库里那些基因组学技能的产出，现在也能直接画出来。面板多了第 4 个标签页「基因组」。

| 图 | 画什么 | 对应技能 |
|---|---|---|
| **进化树** | Newick 解析（支持分支长度、引号标签、注释、bootstrap）· 矩形布局 · 叶子按谱系着色 · 节点标支持率 · 带比例尺 | `phylogenetics`、`etetoolkit` |
| **序列比对** | 残基按化学性质分六类着色 · 顶部逐列保守度轨道 · 列坐标自适应 | `protein_sequence_msa` |
| **GO/KEGG 富集** | 按 p 值排序的气泡图：大小 = 基因数、颜色 = −log10(p)、描边 = 分类，并导出统计表 | `pathway-enrichment`、`reactome_database` |
| **全基因组变异** | 染色体线性图，SNP/INDEL 在上、CNV/SV 在下，标签自动错层 | `pysam`、`tiledbvcf` |
| **覆盖度轨道** | 多样本填充曲线 + 基因模型 + 位置轴 | `deeptools`、`pysam` |
| **火山图** | 差异表达：阈值线 + 方向着色 + 可标注基因 | `pydeseq2` |

两处刻意的取舍，都是画出来看过才定的：

- **质粒给最小可见宽度。** 4.41 Mb 的染色体旁边放 4 kb 的质粒，按真实比例不足 1 像素 ——
  第一版画出来就是「什么都没有」，只剩一个长度标注。现在给 4px 下限，长度差异交给标注说明。
- **覆盖度每条轨道用自己的峰值当刻度。** 三条轨道共用一个全局最大值时，看起来像「深度差不多」，
  而实际峰值是 213 / 180 / 85。

### 1.0.1 · 修一个让图表整片空白的 bug

- **图表面板被静默跳过**：绘图区算出来 45.5px，撞上兜底判断 `box.h < 46`，所有面板都被跳过 ——
  只剩标题、图全没了，而且不报错。现在有最小可用高度，装不下就把画布撑高、外层滚动。
- **技能库面板抢走一半画布**：`.sciviz-skills` 设了 `display:flex`，压过浏览器默认的
  `[hidden]{display:none}`，于是技能库面板在每个标签页都显示着，和画布各占一半
  （实测画布只剩 257px）。同一个坑还让浮窗关不掉。
- **长轴标签压住图注**：`普通饲料 − 15%大豆饲料` 斜排需要 103px，轴带只留了 40px。
